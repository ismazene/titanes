# Paintball Titanes

Página web estática de presentación para un negocio ficticio de paintball ("Experiencia Táctica Extrema"). HTML, CSS y JavaScript, sin dependencias de compilación.

## Contenido

- `index.html`: la página.
- `styles/style.css`: estilos.
- `scripts/main.js`: interacción y animaciones.

## Cómo verla

Abre `index.html` en el navegador.

Proyecto de práctica de maquetación web; el contenido es ficticio.
